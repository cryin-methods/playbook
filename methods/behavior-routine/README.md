# 行为纪律 (behavior-routine)

> 健身 / 饮食 / 交易 / 承诺——四个高频场景的轻量日志与规则。
> 解决根因：**不是意志力，是工具错配**。

## 是什么

把"重复犯的失误"从"低频重大决策工具"（11 字段决策模板）搬到"高频轻量日志"。每个场景：3 字段记录 + 触发规则 + 失败定义。

## 四个场景

| 场景 | 规则 | 失败定义 |
|---|---|---|
| 健身 | 练二休一（背 / 胸 / 休）| 没到场地 |
| 饮食 | 见 [`behavior-routine/diet-baseline.md`](./diet-baseline.md)（增肌 2136 kcal）| 连续 3 天不做有氧 |
| 交易 | 入场前写死止损数字；亏损后 24h 禁加仓；情绪激活 30 分钟不下单 | 违反任一条 |
| 承诺 | 统一话术"我看下日程，今晚回你"；24h 冷却 | 当场答应 |

## 记录载体

`D:\decision-log\行为日志.md`（四场景 + 对账表）

## 定时任务

| 任务 | cron |
|---|---|
| 行为日志·每日打卡 | `0 22 * * *` |
| 行为日志·每周对账 | `0 21 * * 0` |

## 铁律

1. **记录只记不评价** — 改规则只在周对账做
2. **触发点必须可观测** — 不接受"状态不好 / 太累"
3. **某条规则连续两周做不到 → 改规则，不加意志**
4. **失败定义要硬** — 没硬定义 = 不会失败 = 规则没用

## 已知坑

- 健身"练二休一"绑星期（周一/三/五）→ 周末乱了全乱 → 改为绑**次数不绑星期**
- 计划档 vs 实际档：开练前不降档（开练降档=偷懒），开练后前 1-2 个动作没力气才降档
- 增肌饮食碳水公式起点 280g，但 2 周后要按"饥饿感"调——**不靠意志**靠反馈
- 交易"亏损后 24h 禁加仓"看似简单，但**情绪上头时会忘了** — 写在 SOUL 不够，要写进 trading-view / freqtrade 的机器人逻辑
